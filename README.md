# E-Commerce Data Analysis using SQL & Python

## Project Overview

This project analyzes Brazilian e-commerce data using SQL and Python to answer 25 business-driven questions.

## Tools & Technologies

- MySQL
- SQL
- Python
- Pandas
- Plotly
- Jupyter Notebook

## Analysis Areas

- Sales and revenue analysis
- Customer analysis
- Product performance
- Payment analysis
- Seller performance
- Delivery and freight analysis
- Customer retention
- Customer segmentation

## SQL Concepts Used

- JOINs
- GROUP BY
- CTEs
- Window Functions
- DENSE_RANK
- Moving Averages
- Cumulative Analysis
- Year-over-Year Analysis

## Project Files

- `Ecommerce_Data_Analysis.ipynb` — Complete SQL and Python analysis

## Objective

The objective of this project is to use data analysis techniques to identify patterns, answer business questions, and generate actionable insights from e-commerce data.
